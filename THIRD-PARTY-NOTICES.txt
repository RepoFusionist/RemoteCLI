Remote CLI - third-party notices
================================

This file covers third-party components used by the Remote CLI Windows desktop
application and its optional UI plugin package. It does not state or imply a
license for Remote CLI's own source code, which has no license grant in this
repository. Full license texts are in the ThirdPartyNotices folder and are
copied next to RemoteCli.Desktop.exe in every build and publish output.

When redistributing the application, ship RemoteCli.Desktop.exe together with
this file and the ThirdPartyNotices folder. Several MIT components have no
copyright header inside their minified sources (xterm.js, the shiki bundle),
so the accompanying texts are the only place their attribution survives.
