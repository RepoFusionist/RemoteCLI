网络搜索服务

            

              
搜索提供方
自动模式优先使用 Exa；也可以直接调用 DeepSeek Search API，未配置密钥时回退到 DuckDuckGo HTML。

              

                
              

            

            

              
搜索 API 密钥
仅保存在本机设置文件；Exa 使用 EXA_API_KEY，DeepSeek 使用 DEEPSEEK_API_KEY。DeepSeek 为空时会复用自定义网关 API 密钥。

              

            

            

              
搜索服务地址
Exa 默认 https://api.exa.ai；DeepSeek 默认 https://api.deepseek.com/v1/tools；可填写兼容服务的 HTTPS 或本机回环地址。

              

            

            

              
搜索超时（秒）
一次完整搜索的总预算，范围 5–120 秒；不会为备用端点各等待一遍。

              

            

          

          

            
MCP 服务器

            
仅启用的服务器可用。stdio 会在本机启动程序；HTTP 会连接指定地址。连接和工具调用需逐次批准。配置会明文保存，请勿在地址或参数中填写凭据；stdio 的 env 和 HTTP 的 headers 只填写本机环境变量名。

            
            
            
示例：[{"id":"local","name":"本地工具","transport":"stdio","command":"程序路径","args":[],"enabled":false}]；HTTP 使用 transport: "http" 和 url。
