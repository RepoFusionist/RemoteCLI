# Office preview fixtures

`preview-modern.docx` and `preview-modern.xlsx` are generated specifically for
these tests. They contain, respectively, an image and table, and styled cells
and a chart.

`preview-legacy.doc` comes from [Apache POI's simple.doc](https://github.com/apache/poi/blob/trunk/test-data/document/simple.doc).
`preview-legacy.xls` comes from [Apache POI's SimpleChart.xls](https://github.com/apache/poi/blob/trunk/test-data/spreadsheet/SimpleChart.xls).
